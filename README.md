# ATM System in C++

A simple ATM System project built using C++ for beginners.

## Features
- Deposit Money
- Withdraw Money
- Check Balance
- Menu Driven Program
- Uses Functions
- Uses Switch Case
- Uses Loops
- Uses Conditional Statements

## Technologies Used
- C++
- Console Application

## How It Works
The program displays an ATM menu where the user can:

1. Deposit money
2. Withdraw money
3. Check account balance
4. Exit the program

The system keeps running until the user chooses Exit.
